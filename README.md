# Campus-Central-Unified-Student-Journey-Platform
#About :
Unified Student platform featuring smart attendance buffers, role-based workflows, and a PostgreSQL/Prisma/Redis backend/Next.js.

#Description :
CampusCentral is a Next.js 14 modular monolith that unifies academic deadlines, assignments, exams, and notices into one place. Built with PostgreSQL, Prisma, and Redis, it features a smart attendance buffer engine and strict server-side RBAC for students, faculty, and admins.
